# interview-prep

## 步骤
1. 问清目标岗位和公司（可选：JD 原文），以及面试语言（中文或英文）。
2. 读取 `$BRAIN_DIR/30-projects/` 和 `$BRAIN_DIR/10-knowledge/career/`。
3. 选出与岗位最相关的 3 个项目，每个写成 STAR 结构，口述约 2 分钟。
4. 每个故事附 3 个可能的追问和答题要点。
5. 结果追加到 `$BRAIN_DIR/10-knowledge/career/star-stories.md`，按岗位分节。

## 规则
- 只使用复盘中已有的事实和量级，不编造数字。
- 缺信息的地方列成问题，请用户补充。
